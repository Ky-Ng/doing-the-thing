## Goals

1. Reading
    1. Read Saphra [\[2506.15872\] Hidden Breakthroughs in Language Model Training](https://arxiv.org/abs/2506.15872)
        - POLCA (Projection Oriented Loss Change Allocation) is a modification of LCA (Loss Change Allocation) which disaggregates the loss by (1) each datapoint and (2) an orthonormal basis determined by the eigenvector w/ the largest eigenvalue to do unsupervised clustering/classification of data points and how they contribute to the loss
        - I think this is pretty interesting for big models where you don’t have an a priori understanding of what exact skills you are looking for. I think for now, plotting a phase transition for different syntactic structures is a very good first order approximation of this
    2. Read Multilingual morphology inflection paper <https://arxiv.org/abs/2410.09223v1>
        - There’s shared circuitry cross linguistically for Tense Marking (past tense) and IOI
        - Takeaway: Using path patching seems likes a good idea
    3. Temporal Recurrence: <https://arxiv.org/abs/2609.12531> (thanks Tony for sharing)
        - Cool: trade layer depth for time
    4. Variable Binding: <https://arxiv.org/abs/2505.20896>
        - Variables and their values live in different subspaces
        - Takeaway:
            1. Training dynamics shows that heuristics are used early on and continued to be used later too if the value appears early in assignment
            2. Use causal abstraction to check flow of variable assignment (very lookbacks-esque) but never vary the syntax of assignment
    5. Chris Potts lexical semantics
